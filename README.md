# 学苑 · 高校学生管理系统

Vite + React + TypeScript。V1 覆盖学籍、组织、开课选课、课表与报表。

## 启动

```bash
cd student-management-system
npm install
npm run dev
```

浏览器打开终端提示的本地地址。
