# 学苑 · 高校学生管理系统

基于 Vite、React 和 TypeScript 构建的高校学生管理系统，采用前后端分离架构，集成 LLM 智能增强能力，覆盖学籍管理、组织管理、课程管理、选课、课表与数据报表等场景。

### 技术选型

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端 | React 19 + TypeScript + Vite | SPA 单页应用 |
| AI 增强 | OpenAI GPT-4o-mini | 智能问答/报表解读/课程推荐 |
| 后端 | Python 3.12 + FastAPI | 异步高性能框架 |
| 数据库 | PostgreSQL 16 | 主从读写分离 |
| 缓存 | Redis 7 | 分布式锁 + 名额缓存 |
| 任务队列 | Celery + Redis | 选课削峰填谷 |
| 部署 | Docker + K8s | 弹性伸缩 |

### AI 智能增强

| 功能 | 模块 | 说明 |
|------|------|------|
| 智能问答助手 | `AiAssistant.tsx` + `llm.ts` | 浮窗对话，解答系统使用问题 |
| 报表智能解读 | `Reports.tsx` + `llm.ts` | AI 分析数据，生成洞察报告 |
| 选课智能推荐 | `CourseRecommend.tsx` + `recommend.ts` | 基于专业/时间/容量的课程推荐 |

**设计原则：**
- **高内聚**：`recommend.ts`、`llm.ts` 独立封装，不依赖 UI
- **低耦合**：组件通过 Props/回调通信，可独立复用或移除

### 高可用设计（选课高峰）

- **分布式锁**：Redis SET NX 防止同一课程超卖
- **三重校验**：Redis DECR → MySQL 唯一索引 → 乐观锁
- **限流熔断**：单用户 1次/秒，全局 10000 QPS
- **读写分离**：查询走从库，写入走主库
- **弹性伸缩**：HPA 根据 CPU 自动扩容（4→32 pods）

### 选课核心流程

```
学生点击选课
     │
     ▼
┌─────────────────────────────┐
│ 1. JWT 认证 + 限流           │  网关校验身份，单用户 1次/秒
└────────────┬────────────────┘
             ▼
┌─────────────────────────────┐
│ 2. 获取分布式锁              │  Redis SET NX 锁 offering_id
│    (SET NX EX 3)            │  同一教学班串行处理
└────────────┬────────────────┘
             ▼
┌─────────────────────────────┐
│ 3. Redis 缓存校验            │
│    - 已选？→ 拒绝            │  SISMEMBER 学生已选集合
│    - 时间冲突？→ 拒绝         │  内存计算冲突检测
│    - 名额不足？→ 拒绝         │  DECR 原子扣减名额
└────────────┬────────────────┘
             ▼
┌─────────────────────────────┐
│ 4. 写入 PostgreSQL           │  INSERT ... ON CONFLICT
│    唯一索引兜底防重复          │  DO NOTHING
└────────────┬────────────────┘
             ▼
┌─────────────────────────────┐
│ 5. 更新缓存 + 释放锁 + 返回   │
└─────────────────────────────┘
```

**防超卖三重保障：**

| 顺序 | 机制 | 作用 |
|------|------|------|
| 第一道 | Redis `DECR` 原子操作 | 高并发下快速拦截 |
| 第二道 | MySQL 唯一索引 `uk_student_offering` | 防止重复选课 |
| 第三道 | 乐观锁 `WHERE enrolled_count < capacity` | 最终一致性兜底 |

## 功能列表

### 核心功能
- 角色登录：教务管理员、教师、学生
- 学生信息与学籍管理
- 院系、专业与组织架构管理（支持新增、编辑、删除、级联清理）
- 学期管理：设置选课时间窗口与当前学期
- 课程与开课管理（支持新增、编辑、删除）
- 学生选课与课程安排（容量校验、时间冲突检测）
- 教师可查看授课学生名单
- 教师课表、学生课表与个人资料
- 数据看板与统计报表（CSV 导出）
- 操作审计日志（支持筛选）
- 本地演示数据初始化与重置

### AI 智能增强
- 智能问答助手：右下角浮窗，解答系统使用问题
- 报表智能解读：一键生成数据分析洞察
- 选课智能推荐：基于规则引擎的课程匹配推荐（匹配分 0-100）

### 删除安全
- 所有删除操作二次确认弹窗
- 级联清理关联数据（学院→专业→班级→学生）

## 快速启动

### 前端

```bash
git clone https://github.com/tt519660/student-management-system.git
cd student-management-system
npm install
npm run dev
```

启动后，打开终端中显示的本地地址，通常为 `http://localhost:5173`。

### 后端（可选）

```bash
cd backend
pip install -r requirements.txt
python main.py
```

后端运行在 `http://127.0.0.1:8000`，API 文档见 `http://127.0.0.1:8000/docs`。

> 后端未启动时，前端自动使用本地 localStorage 数据，不影响使用。

### 生产构建

```bash
npm run build
npm run preview
```

### 代码检查

```bash
npm run lint
```

## 配置说明

项目使用 Vite 默认配置，开发环境无需额外配置文件或数据库即可运行。演示数据保存在浏览器本地存储中，首次启动会自动初始化。

如需修改本地开发端口，可在 `vite.config.ts` 中配置：

```ts
import { defineConfig } from 'vite';

export default defineConfig({
  server: {
    port: 5173,
  },
});
```
